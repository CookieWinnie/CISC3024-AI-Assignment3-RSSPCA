# ORL data provenance

- Original database: ORL / AT&T Laboratories Cambridge faces, originally 112 x 92.
- Actual resource used: ORL.mat from Jing Wang's Figshare dataset record 27643026.
- Metadata: https://api.figshare.com/v2/articles/27643026
- Record: https://doi.org/10.6084/m9.figshare.27643026
- File URL: https://ndownloader.figshare.com/files/50337435
- Downloaded in this session on 19 November 2026, 4,122,269 bytes.
- SHA256: f59adc3a173cca9685cafc13645f6af4e05e62a16190049c63ebedfeeece1fcd
- Verified x shape: (56, 46, 400); label shape: (400, 1).
- Labels: integers 1 to 40, exactly 10 images in every class.
- Pixel values in the MAT file: 2.66131591796875 to 234.78573608398438.
- The authors have already resized these images. No further resizing is performed;
  original 112 x 92 files were not downloaded or independently compared.
- Images are divided by 255 and flattened in MATLAB/Fortran column order.
- Figshare's recorded license is CC BY 4.0. This is the repository's metadata claim;
  no separate legal determination of underlying portrait rights was made.
- The resource is used locally for coursework. Raw faces and derived image-bearing
  arrays are excluded from public Git and from the source ZIP.
